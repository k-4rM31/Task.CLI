# Task.CLI

Une application en ligne de commande (CLI) rapide, robuste et structurée pour gérer vos tâches, développée entièrement en **Dart pur** directement depuis le terminal.

Le projet implémente une **Clean Architecture** stricte pour garantir la testabilité, la maintenabilité et une séparation nette entre la logique métier (Domain), l'analyse syntaxique (Presentation) et le stockage (Infrastructure).

Developper dans le cadre de ma formation FlutterFire Summer Camp 2026 sur la platforme NextFlutter
